# Technical writing portfolio

I am a senior technical writer with 6+ years producing standard operating procedures,
user guides, process maps and system documentation for transportation and regulated
industries. This set shows the three documentation types I produce most often:
standards and style guidance, step based procedures, and requirements with acceptance
criteria.

## Samples

- **[Style guide excerpt](style-guide-excerpt.md)**
  House style rules covering voice, capitalization, terminology, numbers and
  accessibility. *Demonstrates standards ownership, consistency and accessibility.*

- **[Standard operating procedure](standard-operating-procedure.md)**
  An operations procedure with a process diagram, numbered steps, expected results,
  exception handling and a revision history. *Demonstrates procedure writing,
  process mapping and structured authoring.*

- **[Requirements and acceptance criteria](requirements-and-acceptance-criteria.md)**
  User stories, Given/When/Then acceptance criteria and a traceability matrix.
  *Demonstrates requirements analysis and lifecycle documentation.*

## About this set

These are scenario based samples written to stand on their own. No client or employer
content is included, so nothing here depends on a confidentiality agreement. Each
sample opens with a short context block describing the scenario and what it
demonstrates.

Written in Markdown and version controlled with Git.
